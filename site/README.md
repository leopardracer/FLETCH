# site/

The FLETCH marketing/landing page — a single self-contained `index.html`
(all images inlined as data URIs, no build step, no dependencies). This is
separate from `web/`, which is the actual product dashboard served by the
running app (`src/api/server.ts`).

## Deploying (Vercel)

This repo's root isn't a static site — `site/` is just one folder in it.
When importing this repo into Vercel:

1. **Add New → Project → Import Git Repository** → select `FLETCH`
2. In the import screen, expand **Root Directory** and set it to `site`
3. Framework preset: **Other** (no build command needed — it's a static file)
4. Deploy

Updating the live site after this is just editing `site/index.html` and
pushing to `main` — Vercel redeploys automatically.

## Updating

The file is generated by inlining `assets/*.png` as base64 data URIs into
a single HTML page. If you're editing content by hand, edit directly in
`site/index.html` — there's no separate source file to rebuild from.
